# Kashide

気に入った歌詞から曲を選べるサービス

### ペルソナ像
- 歌詞重視派の人(8%程度いる模様 n=90)
- 中々新しい曲にトライできない人
- マイナーソングを知ってほしい人


### 課題点
- 著作権の問題
=> JASRACと正式に契約を結びました。 2022.10.24


### 実装したいNice-to-have機能
- 歌い手にリクエスト機能（クラファンのような形で）
- ランキング機能
- スーパーライク機能
